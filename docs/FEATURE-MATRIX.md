# 功能矩阵（1.0.0；0.8.3 稳定回退基线）

| 范围 | 当前状态 | 证据 / 后续门槛 |
|---|---|---|
| 扩展骨架、启停、清理 | 已实现，待真实宿主 | `manifest.json`、`src/extension.js` |
| 4.3 手机 UI 与导航 | 固定前端及配套悬浮宿主已恢复 | UI SHA 强制校验；本地截图与 DOM smoke 已通过，待真实宿主人工对比 |
| 独立状态核心 | 已实现 | `HypnoState/v1` 是唯一运行状态源；聊天 metadata 持久化；无 TH/MVU 完整运行 |
| 中国 / 日本 / 世界书生成模板 | 已实现 | 设置页可切换中国/日本，或选择世界书生成聊天级结构化适配包 |
| 角色、头像与四类导入 | 已实现 | 角色变量分为 runtime、extensions、compatibility；旧 core/custom 自动迁移；异常包与完整往返仍需扩大 fixture |
| 本轮输入暂存 | 已实现为手机应用 | 可编辑玩家本轮输入；支持写入输入框或经宿主发送按钮直接发送，暂存仍统一提交 |
| 信息 | 已实现为手机应用 | 资源、变量格式、桌宠人物与变量楼层均在手机内显示；所有操作按钮均有状态反馈；外部右侧栏停止显示 |
| 4.3 应用 UI | 17/17 个主屏入口本地路由通过 | 23 项 `PhoneAppModule/v1` 已登记；真实模型行为仍待宿主验收 |
| 桌宠、手机拖动与缩放 | 本地交互 smoke 通过 | 爱丽莎/百花切换、触屏长按菜单、5 个边框拖动区、2 个无标志等比例缩放热区；待真机触控复核 |
| TH / MVU 兼容桥 | 已实现可选桥 | 外部变量先导入 HypnoState，UI 不直接读取 TH/MVU；真实存在/缺失双环境待验收 |
| APP Data Service | 已接入运行应用 | 地图、监控、日历、课程表、成就/任务、打工和兼容变量统一通过服务读取状态、地区模板及世界书接口 |
| 世界书适配器 | 已接入设置生成流程 | 地图、特殊地点与监控三门读取同一批选定世界书；生成结果存于当前聊天本地存储，可单独清空，原书零修改 |
| 混沌心海 | 本地交互 smoke 通过 | 保留原分区与帖子 UI；每轮对话后调用酒馆内置模型更新，顶部标题可手动更新，聊天级帖子最多保留20条 |
| 原4.3脚本共存 | 已做命名空间隔离 | 插件使用独立单例键、DOM id、就绪事件与位置存储；真实原卡同开待用户验收 |
| 伴生世界书 | 已实现所有权、来源哈希、快照冲突门控 | 原书零修改；真实接口幂等测试待宿主验收 |
| 模型插头 | 已实现自定义直连 | 从基础 URL 加载 `/models`，列表选择后回填只读模型名，并调用 `/chat/completions`；真实供应商 CORS、超时/无效 JSON/拒绝/泄漏仍待验收 |
| 邂逅角色库 | 保留空库与导入能力 | 当前版本不预置偶遇人物/角色包，并一次性清理旧内置库；后续玩家导入仍可保存 |
| 真实连续多轮运行 | 未验收 | RC 阻断项 |
| 人工视觉确认 | 未验收 | RC 阻断项 |
| 许可与署名材料 | 待补原件 | 1.0 阻断项 |

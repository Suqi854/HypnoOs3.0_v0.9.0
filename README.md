# 催眠手机 HypnoOS 3.0

独立的 SillyTavern 前端扩展。当前源码版本为 `1.0.0`，稳定回退基线仍为 `0.8.3`：保持既有4.3专属界面和应用入口不变；区域地图、特殊地点与监控地点从同一批世界书生成，特殊地点继续使用原机密坐标界面，不回退固定地点目录。正式发布仍需真实宿主逐项验收。

## 当前能力

- 三层数据域：浏览器全局资源、角色资料、聊天状态。
- 中国通用版、日本通用版和完全自定义初值。
- PNG / JSON / CharX / HypnoOS ZIP 角色导入与头像校验、IndexedDB 存储。
- 手机内“本轮输入”应用：自动读取酒馆当前草稿，允许编辑玩家本轮输入，并与批量 APP 操作统一写入输入框（不自动发送）。
- 手机内“信息”应用：集中展示资源、变量格式、桌宠人物和变量楼层；桌面右侧不再占用独立信息栏。
- 手机内“数据库”应用：只读展示数据库本体的实时表格；检测到 `AutoCardUpdaterAPI` 时，人物、主角资料、地点/时间、库存和任务会直接同步到现有手机应用，每轮不再调用模型生成档案世界书。
- 信息应用的变量检查、修复、桌宠切换和楼层操作均提供处理中、成功或失败反馈。
- 人物档案会合并 MVU 与当前角色世界书中的明确人物设定，并可在档案顶部手动修正男女归类。
- 手机内“头像库”支持批量导入 PNG/JPEG/WebP/GIF，并将头像应用到所选角色；大文件存入 IndexedDB。
- 地图、监控、日历、课程表、成就和任务、打工、混沌心海统一消费结构化适配包，不再直接展示世界书原文；监控三门分别使用所选世界书生成的地点与安排，设置中可单独清空生成数据。
- 混沌心海保留原分区与帖子 UI，每轮对话后由酒馆内置模型自动更新；点击顶部标题可手动更新，当前聊天最多保留20条帖子。
- 邂逅保留导入与编辑能力；当前版本不预置偶遇人物或角色包，并会一次性清理旧内置库数据。
- 世界书只读扫描、确定性映射草案、AI 辅助草案、差异预览和 HypnoOS 伴生世界书。
- 模型插头使用 OpenAI 兼容自定义直连端点。密钥不会进入扩展设置、导出包、世界书或日志。
- 设置保持“聊天与变量 / 模型插头 / 日志”三个独立板块。
- 自定义直连按“端点与密钥 → 加载模型 → 列表选择 → 保存”配置；模型名为只读回填项。
- Tavern Helper / MVU 可选同步；缺失时手机核心仍能运行。
- `HypnoState` 是唯一运行状态源；角色 runtime、扩展数据和旧变量兼容数据分区保存，手机应用统一经 App Data Service 访问。
- 世界书档案复用已有的人物状态和剧情上下文条目，并自动收纳旧重复条目与重复正文；内置催眠规则已移除指令白名单、结果分类和输出硬检查三个冗长段落。
- 4.3 桌宠、点按/触屏长按、人物切换和手机边框拖动已恢复；桌宠长按菜单的“通用”入口打开独立扩展设置。
- 手机根文档禁止整页滚动，四边透明拖动热区继续工作；帮助、设置、人物档案等应用仍在各自内容区滚动。
- 手机下方左右角具有完全透明的缩放热区，可同步等比例缩放机壳、应用和全部内容；不显示手柄或提示图标。

## 安装与预览

SillyTavern 最低版本为 `1.18.0`。将发布 ZIP 解压到 `public/scripts/extensions/third-party/HypnoOS3.0` 后，在扩展管理中启用。不要把源码仓库中的 `legacy/` 安装进宿主；构建包会自动排除它。

```powershell
npm test
npm run check
npm run build
npm run preview
```

静态预览地址为 `http://127.0.0.1:6633/`。静态预览不等于真实酒馆验收。

## 安全边界

- 角色包、世界书和 AI 输出全部视为不可信数据。
- 导入器不执行卡内脚本、HTML、宏或远程 URL。
- 来源世界书只读；写入操作只针对带 HypnoOS 所有权元数据的伴生世界书。
- 伴生书重扫比较来源哈希和上次生成快照；检测到人工修改或外来条目时阻止覆盖。
- 手机 UI 是许可基线内的本地固定代码，不从网络加载脚本。
